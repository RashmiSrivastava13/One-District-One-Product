# One-District-One-Product
This Power BI dashboard provides a comprehensive analysis of the One District One Product (ODOP) initiative, visualizing data from 700+ districts across India. 
## 📌 Key Insights

🔹 **Total States Covered**: 36  
🔹 **Total Districts Analyzed**: 1241  
🔹 **Unique Products**: 836  
🔹 **GI Tag Products**: 256  
🔹 **Product Categories**: 10+  
🔹 **Sectors Covered**: Primary, Secondary, Tertiary, Others

---

## 📊 Dashboard Highlights

- 🗺️ **Interactive Product Distribution Map**  
  Visualizes product locations across India, color-coded by sector.

- 🧭 **GI Tag Status Insights**  
  View number of GI-tagged products using a dynamic card.

- 📈 **Products per Sector**  
  Column chart representing the distribution of products across economic sectors.

- 🍽️ **Product Category Donut Chart**  
  Shows percentage distribution across categories like Agriculture, Handicrafts, Food Processing, etc.

- 🧰 **Filter Panel**  
  Easily slice the data by:
  - State  
  - Sector  
  - Product Category  
  - Ministry  
  - GI Tag Status

---

## 📂 Data Columns

- `State`  
- `District`  
- `Product Name`  
- `Sector` (Primary/Secondary/Tertiary/Others)  
- `Category` (e.g., Agriculture, Dairy, Handloom)  
- `GI Tag Status` (Yes/No)  
- `Ministry` (e.g., DC Handicraft, DC Handlooms)
